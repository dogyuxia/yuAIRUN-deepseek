# 出题页面 UI 扩展设计 — 知识库选择器

> **关联设计**：[design.md](./design.md)
> **目标文件**：`src/pages/topic-input/index.tsx` + `index.scss`
> **当前状态**：已有"自由输入/粘贴链接/上传文档"三种输入方式

## 一、设计目标

在现有的出题页面（topic-input）中，新增**知识库选择区域**，让用户可以在出题时选择从哪个知识库检索资料，以及使用哪种搜索模式。

## 三、组件设计

### 3.1 知识库选择卡片 (KnowledgeBaseSelector)

一个可折叠的卡片组件，展示用户的知识库列表。

```
┌─────────────────────────────────────┐
│ 📚 知识库    [▼ 展开/收起]           │
│                                     │
│ ┌ ○ 🌐 AI 搜索出题 ──────────────┐ │  ← 默认选项
│ │   联网搜索最新资料出题            │ │
│ └────────────────────────────────┘ │
│ ┌ ○ 📚 AI Agent 知识库 ─────────┐ │
│ │   系统内置 · 21份文档 · 已索引   │ │  ← 带状态标签
│ └────────────────────────────────┘ │
│ ┌ ○ 📚 计算机网络教材 ───────────┐ │
│ │   12份文档 · 已索引             │ │
│ └────────────────────────────────┘ │
│ ┌ ○ 📚 我的笔记 ────────────────┐ │
│ │   5份文档 · 3份处理中          │ │  ← 显示处理进度
│ └────────────────────────────────┘ │
│                                     │
│ [+ 管理知识库]                       │  ← 跳转到知识库管理页
└─────────────────────────────────────┘
```

**交互规则**：
- 点击任一知识库 → 选中，自动展开搜索模式选择
- 点击"AI 搜索出题" → 不选知识库，用 Tavily 搜索（现有行为）
- 折叠状态下只显示当前选中的选项
- 知识库加载中显示骨架屏

### 3.2 搜索模式选择器 (SearchModeSelector)

当选中的是具体知识库时，显示搜索模式选项。

```
┌─────────────────────────────────────┐
│ 🎯 搜索模式                        │
│                                     │
│ [🔍 仅知识库] [🕸️ 仅AI搜索] [🔀 混合]│
│                                     │
│ 当前选择：仅知识库                    │
│ 📖 将从此知识库检索相关资料出题        │
└─────────────────────────────────────┘
```

**三种模式说明**：

| 模式 | 图标 | 检索方式 | 适用场景 |
|:----:|:----:|---------|---------|
| **仅知识库** | 🔍 | 只从 ChromaDB 检索 | 私密文档、考试复习 |
| **仅 AI 搜索** | 🕸️ | 只从 Tavily 搜索 | 最新公开知识 |
| **混合模式** | 🔀 | ChromaDB + Tavily | 兼顾私密和公开知识 |

### 3.3 知识库标签 (KnowledgeBaseTag)

选择知识库后，在"AI 生成题目"按钮上方显示简洁标签：

```
📚 AI Agent 知识库 | 🔍 仅知识库
```

点击标签可快速回到知识库选择器。

## 五、交互流程

```
用户打开出题页面
    │
    ▼
加载知识库列表（API 请求，显示骨架屏）
    │
    ▼
┌─────────────────────────────────────┐
│ 用户选择知识库                       │
│                                     │
│ 不选择 (默认) → 隐藏搜索模式选择       │
│                  → 使用传统搜索出题    │
│                                     │
│ 选择知识库 → 展开折叠的知识库卡片       │
│            → 显示搜索模式选择器        │
│            → 用户选择搜索模式          │
│            → 点击"AI 生成题目"         │
└──────────────┬──────────────────────┘
               │
               ▼
发送请求（携带 knowledgeBaseId + searchMode）
    │
    ▼
根据 searchMode 路由到不同出题链
├── search → Tavily 搜索出题
├── knowledge_base → ChromaDB RAG 出题
└── hybrid → ChromaDB + Tavily 融合出题
```

## 六、状态展示

| 状态 | 表现 |
|:----:|------|
| **加载中** | 骨架屏（灰色脉冲块） |
| **空状态** | "还没有知识库，去创建一个" + 跳转按钮 |
| **正常** | 展示知识库列表，带文档数和状态标签 |
| **处理中** | 文档状态标签显示"3份处理中" |
| **失败** | 加载失败不展示卡片，显示"重试"按钮 |

## 七、设计原则

1. **不干扰现有流程**：不选知识库时行为和现在完全一致
2. **渐进式展示**：先展示默认的"AI 搜索出题"，选择知识库后才展开更多选项
3. **状态可见**：知识库的索引状态、文档数量一目了然
4. **可折叠**：知识库卡片默认收起，节省页面空间
5. **移动端友好**：单列布局，点击区域充足
