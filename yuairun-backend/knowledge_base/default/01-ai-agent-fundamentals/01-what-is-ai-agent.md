# AI Agent 基础概念

## 什么是 AI Agent？

AI Agent（人工智能代理）是一个能够**自主感知环境、做出决策并执行行动**的智能系统。与传统的 LLM 调用不同，AI Agent 不仅仅是"回答问题"，而是能主动完成多步骤任务。

### 核心特征

| 特征 | 说明 |
|------|------|
| **自主性** | 无需人类每一步干预，自主决策下一步行动 |
| **感知能力** | 能够感知环境状态（通过工具调用、API 响应等） |
| **行动能力** | 能够执行具体操作（调用工具、发送请求、写入文件等） |
| **推理能力** | 能够分解复杂任务、制定计划、反思结果 |
| **记忆能力** | 能够记住之前的对话和行动结果 |

### AI Agent 与传统 LLM 调用的区别

```
传统 LLM 调用：
用户输入 → LLM → 输出（一次完成，无中间步骤）

AI Agent：
用户输入 → LLM 推理 → 决定行动 → 执行工具 → 观察结果
         → 再次推理 → 再次行动 → ... → 最终输出
```

### Agent = LLM + 工具 + 记忆 + 规划

一个完整的 AI Agent 由以下组件构成：

1. **LLM 大脑**：核心推理引擎，负责理解指令、制定计划、生成输出
2. **工具集**：Agent 可以调用的外部能力（搜索、计算器、API 等）
3. **记忆系统**：短期记忆（对话上下文）和长期记忆（向量数据库）
4. **规划模块**：将复杂任务分解为可执行的子步骤

### 简单示例

```
用户："帮我查一下明天的天气，如果下雨就提醒我带伞"

Agent 推理过程：
  1. 用户想知道明天天气
  2. 我需要调用天气查询工具
  3. 根据结果决定是否提醒带伞

Agent 执行：
  → 调用 get_weather(city="用户所在城市", date="明天")
  → 得到结果："明天有雨，温度 18-22°C"
  → 根据结果生成回复："明天有雨🌧️，记得带伞！温度 18-22°C，建议穿外套。"
```

## 关键概念

### ReAct（推理+行动）

ReAct 是 "Reasoning + Acting" 的缩写，是 AI Agent 最核心的工作模式。Agent 在每一步都会：
1. **思考**（Thought）：分析当前状态，决定下一步做什么
2. **行动**（Action）：执行具体的工具调用
3. **观察**（Observation）：获取工具返回的结果
4. **循环**：重复上述过程直到任务完成

### Tool-use（工具使用）

Agent 通过调用外部工具来扩展能力边界。常见的工具类型包括：
- **信息检索**：搜索引擎、数据库查询、文档检索
- **计算处理**：代码执行器、数学计算、数据分析
- **外部服务**：API 调用、发送邮件、操作文件
- **多模态**：图像生成、语音识别、视频处理

### Memory（记忆）

Agent 的记忆分为两个层次：
- **短期记忆**：当前对话上下文（token 窗口内），用对话历史实现
- **长期记忆**：跨会话的知识存储，用向量数据库实现（RAG）

### Planning（规划）

Agent 的规划能力使其能够处理复杂任务：
- **任务分解**：将"写一篇论文"分解为"查资料→写大纲→写正文→修改"
- **自我反思**：执行过程中检查结果质量，必要时重试
- **动态调整**：根据中间结果灵活调整后续计划
