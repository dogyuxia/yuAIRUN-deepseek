# AI Agent 类型

AI Agent 可以根据复杂度、工作方式和应用场景分为不同类型。理解这些类型有助于选择合适的 Agent 架构。

## 按复杂度分类

### 1. 简单反射型 Agent（Simple Reflex Agent）

基于"条件-行动"规则工作，不维护内部状态。

```
感知 → 匹配规则 → 行动
```

**特点**：
- 只关注当前感知，不依赖历史
- 规则是预定义的
- 适用于简单、确定的场景

**示例**：客服聊天机器人中的固定问答路由

### 2. 基于模型的反射型 Agent（Model-based Reflex Agent）

维护内部状态（世界模型），理解环境变化。

```
感知 → 更新内部状态 → 推理 → 行动
```

**特点**：
- 维护环境的内部模型
- 能处理部分可观测的环境
- 决策基于模型预测

**示例**：具有上下文的客服 Agent，能记住用户之前的问题

### 3. 基于目标的 Agent（Goal-based Agent）

除了感知环境，还具有明确的目标，能选择最有利于达成目标的行为。

```
感知 → 推理 → 评估目标 → 选择行动
```

**特点**：
- 有明确的目标函数
- 能规划多步行动
- 在多个可行方案中选择最优解

**示例**：旅行规划 Agent——目标是最小化费用同时最大化体验

### 4. 基于效用的 Agent（Utility-based Agent）

不仅追求目标，还追求"更好"的结果，使用效用函数衡量不同结果的优劣。

```
感知 → 推理 → 计算效用 → 选择最优行动
```

**特点**：
- 有效用函数来量化"好"的程度
- 能在冲突目标之间做权衡
- 会选择概率高且效用大的行动

**示例**：投资 Agent——平衡收益和风险

## 按工作方式分类

### 1. 单 Agent 系统

一个 Agent 独立完成所有任务。

**适用场景**：
- 任务边界清晰
- 不需要多角色协作
- 问题复杂度可控

**优点**：简单、易调试、成本低
**缺点**：能力受限于单一 Agent

### 2. 多 Agent 系统（Multi-Agent System, MAS）

多个 Agent 协作完成复杂任务，每个 Agent 有专门的角色和职责。

```
┌─────────────────────────────────────┐
│          协调 Agent                  │
│  ┌──────┐ ┌──────┐ ┌──────┐        │
│  │研究员  │ │写作者  │ │审核员 │        │
│  │ Agent │ │ Agent │ │ Agent │        │
│  └──────┘ └──────┘ └──────┘        │
└─────────────────────────────────────┘
```

**协作模式**：
- **顺序式**：A → B → C 流水线
- **辩论式**：多个 Agent 讨论达成共识
- **层级式**：一个主 Agent 管理多个子 Agent
- **市场式**：Agent 之间竞价/竞标

**适用场景**：
- 需要多领域专业知识
- 需要交叉验证
- 复杂的工作流编排

### 3. Agent 团队（Agent Team）

Agent 团队是一种更高级的多 Agent 组织形式，具有以下特征：
- **角色分工**：每个 Agent 有明确的角色定义
- **通信协议**：Agent 之间有标准化的消息格式
- **共享记忆**：团队共享一个工作空间或记忆
- **动态组建**：根据任务需求动态组建团队

## 按应用场景分类

| 类型 | 典型应用 | 代表框架 |
|------|---------|---------|
| **对话 Agent** | 客服、助手 | ChatGPT、Claude |
| **代码 Agent** | 编程、调试 | GitHub Copilot、Devin |
| **研究 Agent** | 文献综述、数据分析 | 自定义 |
| **交易 Agent** | 量化交易、套利 | 自定义 |
| **爬虫 Agent** | 数据采集、监控 | 自定义 |
| **协作 Agent** | 项目管理、团队协作 | 自定义 |

## 如何选择 Agent 类型？

选择 Agent 类型时，考虑以下因素：

| 决策因素 | 建议选择 |
|---------|---------|
| 任务简单、规则明确 | 反射型 Agent |
| 需要多步推理 | 基于目标的 Agent |
| 需要权衡多个指标 | 基于效用的 Agent |
| 任务涉及多个专业领域 | 多 Agent 系统 |
| 任务需要人类审批 | 人机协同 Agent |
