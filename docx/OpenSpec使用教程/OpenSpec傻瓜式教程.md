# 🚀 OpenSpec 使用教程——傻子都能懂版

> **OpenSpec 是什么？**
> 简单说：你告诉 AI"我想要个XX功能"，OpenSpec 会帮 AI 先生成**设计文档**，你过目确认后，再让 AI 去写代码。这样 AI 就不会瞎写了，做出来的东西更靠谱。

---

## 📦 第一步：安装 OpenSpec

打开终端（命令行），敲一行命令：

```bash
npm install -g @fission-ai/openspec@latest
```

> 装好后试一下：`openspec --version`，如果能显示版本号，说明装好了 ✅

---

## 🏗️ 第二步：在你的项目里初始化

进到你的项目目录里，运行：

```bash
cd d:\code\AIRUN
openspec init
```

运行后它会问你几个问题：
1. **选 AI 工具** — 选 `github-copilot`（我们就是用的 VS Code + Copilot 嘛）
2. **其他问题** — 一路按回车选默认就行

初始化完成后，你的项目里会多出一个 `openspec/` 文件夹，里面放了配置和模板。

---

## 🤖 第三步：开始一个新功能

在 VS Code 里**新开一个对话**（重要！先清一下上下文），然后输入：

```
/opsx:propose 给AI闯关学园增加一个排行榜功能
```

OpenSpec 会告诉 AI 去生成一个**设计方案**，包括：
- 🔹 这个功能要做什么
- 🔹 需要改哪些文件
- 🔹 分几步完成

**设计方案生成后，你先看一遍**，觉得可以就点继续。不满意就跟 AI 说"改一下哪里哪里"。

---

## ✅ 第四步：确认后让 AI 开始写代码

方案确认没问题了，在同一个对话里输入：

```
/opsx:apply
```

AI 就会按照刚才的设计方案开始写代码，一步一步完成。

---

## 📦 第五步：功能完成后归档

代码写完了，测试通过了，输入：

```
/opsx:archive
```

这会把这个功能的方案设计归档起来，留个记录。以后别人看代码就知道当初为什么要这么设计了。

---

## 🎯 日常使用一句话总结

```
新开对话 → /opsx:propose 我想加XX功能 → 看方案 → /opsx:apply → 搞定 → /opsx:archive
```

---

## ⚠️ 注意事项

| 事项 | 说明 |
|------|------|
| **新功能一定要新开对话** | 不要在旧对话里用 OpenSpec，上下文太乱会导致 AI 理解错 |
| **方案要先看再干活** | AI 生成的方案有可能不符合你的预期，先确认再让他写代码 |
| **不要多个功能混在一起** | 一个功能一个对话，做完一个再做下一个 |
| **备好 Node.js** | 需要 Node.js 20.19.0 以上版本，`node --version` 可以查看版本 |

---

## ❓ 常见问题

**Q: 装 OpenSpec 要钱吗？**
A: 不要钱，开源免费的。

**Q: 会影响我现有的代码吗？**
A: 不会。OpenSpec 只是在项目里多了个 `openspec/` 文件夹放文档，不动你的代码。

**Q: 我不用了怎么卸载？**
A: `npm uninstall -g @fission-ai/openspec`，然后把 `openspec/` 文件夹删掉就行。

**Q: Copilot 识别不了 `/opsx:propose` 命令怎么办？**
A: 先确认 `openspec init` 时选了 `github-copilot`，然后重启 VS Code。
